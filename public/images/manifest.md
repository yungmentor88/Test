# Placeholder image manifest

**Every image in this folder is an AI-generated stand-in. None of them are photographs
of real SHUMI members, and none of them may go live.**

They exist so the wireframe reads like a finished website instead of a page of grey
boxes, and so the art direction can be approved before a camera comes out. All fourteen
are to be replaced with **SHUMI event photography, post-11 Oct**.

- Generated with: Higgsfield Soul 2.0 (`soul_2`), 2K
- Generated on: 4 September 2026
- Delivered as: JPEG, quality 82, progressive, sized to slot (total 1.9 MB for the set)

## The style clause

Appended verbatim to every prompt below, so the whole set reads as one photographer on
one day — same light quality, same colour treatment, same distance from the subject:

> Documentary photograph, available natural light, warm slightly muted colour, fine film
> grain, shallow depth of field, eye-level, candid unposed moment, no studio lighting, no
> retouching, authentic community setting.

## Casting rule applied to every prompt

Cape Verdean heritage is Afro-Portuguese creole and the range inside a single family is
wide. Each prompt names that range explicitly — deep brown, olive and fair skin tones in
the same frame, hair from tight coils through locs and loose waves to straight. The
finished set was reviewed side by side against the test in the brief: *if every woman in
it could be sisters, regenerate.* Four images were regenerated (noted below).
